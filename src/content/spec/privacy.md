## 一句话总结

本站是纯静态的个人博客：**不需要注册、不收集你的姓名/邮箱/手机号、不投放广告**。唯一的第三方统计是 Microsoft Clarity，它只在你与页面产生交互之后才会加载，而且**只要你的浏览器开启了「请勿跟踪」（DNT），它就完全不会加载**。

## 本站会用到哪些信息

### 1. 访问统计：Microsoft Clarity

- **用途**：了解哪些文章有人看、页面有没有问题。
- **收集内容**：页面浏览、点击、滚动、鼠标移动轨迹，以及**会话回放（相当于录屏）**；同时包含浏览器、设备、大致地区等粗略信息。
- **Cookie**：Clarity 会写入 `_clck`、`_clsk` 两个 cookie。
- **数据去向**：由微软（Microsoft）处理与存储，本站只能看到汇总数据。
- **加载时机**：你第一次滚动、点击、移动鼠标或按键之后才加载；如果你一直不操作，则在 10 秒后加载。

### 2. 服务器日志：Cloudflare / GitHub

- 本站主站托管在 Cloudflare Pages，镜像托管在 GitHub Pages。
- 服务方会在服务器日志中记录访问 IP、User-Agent 等，用于安全防护与流量统计，具体保留策略以 Cloudflare、GitHub 各自的隐私政策为准。

### 3. 本地存储：只存在你的浏览器里

- 主题偏好（深浅色、主题色相、卡片样式、音乐播放器状态等）存储在浏览器的 localStorage 中，**不会上传到任何服务器**。清理浏览器数据即可删除。

### 4. 音乐播放器：第三方接口

- 播放器**不会自动播放**。只有你主动点击播放时，才会向第三方 Meting 接口请求数据，并因此把你的 IP、User-Agent 发送给该服务。
- 当前接口为第三方公共实例 `https://meting.mysqil.com/`，**并非本站自建**，音频文件由网易云音乐的服务器提供。
- 如果你不使用播放器，就不会有任何请求发出。

## 本站不会做的事

- 不要求注册或登录，不收集姓名、邮箱、手机号、身份证等个人信息
- 不投放广告，不做用户画像，不向第三方出售或共享你的数据
- 不开启评论区（当前评论功能处于关闭状态）
- 不启用 Live2D 等会额外加载第三方资源的组件

## 如何拒绝统计、保护自己

1. **开启浏览器的「请勿跟踪」（Do Not Track）**：本站会读取这个信号，检测到你开启后**不会加载任何统计脚本**。
2. **使用拦截类扩展**（例如 uBlock Origin）：拦截 `clarity.ms` 域名后统计脚本无法工作。
3. **使用带跟踪保护的浏览器**：Safari、Firefox 等默认就会拦截大部分统计脚本。
4. **清理 cookie 与站点数据**：可一并删除 Clarity 写入的 `_clck`、`_clsk`。
